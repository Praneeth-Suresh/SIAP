Pass 1 - Storyline outline (paragraph-by-paragraph)

Paragraph 1 opens with scarcity: the context window is a tiny stage, and memory policy is the casting director deciding who gets to speak.

Paragraph 2 introduces memory strata as labor specialization, where working memory handles immediate control, episodic memory preserves events, and semantic memory stores compressed structure [48].

Paragraph 3 shifts to decision economics: each retrieval or write is an expected-utility trade between downstream accuracy and immediate compute/token cost [33] [34].

Paragraph 4 braids compression and retrieval: rate-distortion says what fidelity is worth paying for, while indexing/reranking says how quickly and reliably the right evidence can be recovered [35] [46] [15].

Paragraph 5 closes with resilience and contamination control, showing that forgetting is not negligence but active safety policy when stale or poisoned context threatens action quality.
