# Support

Use the repository's **Question** issue template for help with:

- building the site or publication PDF;
- navigating the manuscript or its examples;
- choosing the right contribution surface;
- understanding a documented project decision.

For reproducible defects, use the **Bug report** template. For new ideas, use the **Feature request** template. Do not use public issues for security reports; see [SECURITY.md](SECURITY.md).

Please include the command you ran, your operating system and Python version where relevant, the expected result, and the smallest useful excerpt of output. Remove credentials and private data first.
