Memory Systems, Context, and Retrieval

Memory is policy, not pile: retain, compress, retrieve, forget. A capable agent treats context as scarce capital and allocates it with the same seriousness we reserve for money, time, and safety.

Formal memory control problem

Let memory state be (m_t=(w_t,e_t,s_t)): working, episodic, and semantic stores.
A memory controller chooses operations (u_t \in {\texttt{write},\texttt{compress},\texttt{retrieve},\texttt{evict}}) by [ u_t = \mu_\theta(m_t,h_t), ] to optimize [ \max_\mu\ \mathbb{E}!\left[\sum_t \gamma^t \big(\text{task_utility}_t - \lambda_1\text{latency}_t - \lambda_2\text{token_load}_t\big)\right]. ] This is expected utility under systems constraints: retrieval is good only if it improves decisions more than it costs [33] [34].

One useful control view is Bellman recursion on memory state: [ V^\star(m,h)=\max_{u}\left{r(m,h,u)+\gamma\,\mathbb{E}[V^\star(m',h')]\right}, ] where (r) already includes latency and token penalties [5] [4].

Retrieval and compression mechanics

Sparse retrieval can be represented by BM25 scoring: [ \mathrm{BM25}(q,d)=\sum_{t\in q}\mathrm{IDF}(t)\frac{f(t,d)(k_1+1)}{f(t,d)+k_1\left(1-b+b|d|/\mathrm{avgdl}\right)}, ] while dense retrieval often uses inner-product similarity [ s(q,d)=\langle e_q,e_d\rangle. ] These are not rival religions; they are complementary indexing geometries with different failure modes [46] [15] [47].

Compression policy is an information-theoretic trade: [ R(D)=\min_{p(\hat x|x):\mathbb{E}[d(X,\hat X)]\le D} I(X;\hat X), ] which says you should only pay bitrate for distinctions that matter to downstream decisions [35].

For retrieval-augmented generation, evidence quality propagates to output probability: [ p(y\mid x)\approx \sum_{d\in\mathcal{D}k} p\eta(d\mid x)\,p_\theta(y\mid x,d), ] so poor retrieval is not a side issue; it is directly injected into generation dynamics [14].

Three-theory braid

Cognitive multi-store theory gives architectural separation (what kind of memory should hold what), information theory gives compression discipline (what fidelity is worth paying for), and modern retrieval theory gives operational evidence flow (how useful context is recovered in time), so memory becomes an active braid of foresight (saving what future policies will need), responsiveness (retrieving the right fragment now), and resilience (evicting stale or contaminated traces before they derail behavior) [48] [35] [14] [15] [46] [47].

How to study this formally

Evaluate retrieval precision@(k), latency, grounded answer faithfulness, and regret from eviction decisions under fixed token budgets. Stress-test with adversarial distractors and contamination injections, then verify whether policy-level edits (not prompt cosmetics) reduce failure recurrence [16]. If memory policy is not measurable, "long context" is often just expensive amnesia.
