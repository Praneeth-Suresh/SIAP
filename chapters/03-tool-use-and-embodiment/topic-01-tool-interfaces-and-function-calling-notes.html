Alternative rewrite

A tool definition is a constitution, not a convenience method. Once we specify arguments, side effects, and failure semantics, the agent can reason about action instead of improvising with brittle string tricks.

Pass 1 - Migrated ideas from current main topic

The current topic already frames tool use as contract-first orchestration: a function (f:X\to Y) has preconditions, postconditions, and explicit cost/risk terms; legal calls must satisfy (\texttt{Pre}_f), and planners optimize expected utility penalized by cost and risk. The three-theory braid anchors this in schema-typed interfaces, Toolformer-style tool policy learning, and ReAct trajectories as replayable reason-act semantics [13] [12] [11].

Pass 1 - Storyline outline (paragraph-by-paragraph)

Paragraph 1 opens with the claim that API contracts are constitutions: autonomy begins when action is typed, checkable, and auditable.

Paragraph 2 introduces schema validation as epistemic discipline, where malformed arguments are not "model quirks" but illegal state transitions.

Paragraph 3 reframes tool choice as expected-utility optimization under latency, failure risk, and side-effect cost [33] [34].

Paragraph 4 introduces idempotency and exactly-once semantics as resilience mechanisms when retries, timeouts, and partial failures arrive.

Paragraph 5 closes with outage-aware fallback policy: degrade gracefully, escalate safely, and preserve invariant boundaries under uncertainty.

Pass 2 - Research synthesis: equations, theories, and connective tissue

Canonical equations to include: contract legality (\texttt{legal}(u_t)=\mathbf{1}{\texttt{schema_ok}(u_t)\land \texttt{auth_ok}(u_t)}), expected-utility tool selection (u_t^\star=\arg\max_u\mathbb{E}[Q(\sigma_t,u)]-\lambda_c C(u)-\lambda_r R(u)), and long-horizon call policy (V^\star(\sigma)=\max_u{r(\sigma,u)+\gamma\sum_{\sigma'}P(\sigma'|\sigma,u)V^\star(\sigma')}) [5] [4]. Reliability mechanics: idempotent side-effect law (f(f(x,k),k)=f(x,k)) for key (k), retry control (n_{t+1}=\min(n_{\max},n_t+1)), and backoff (d_{t+1}=\beta d_t). External grounding used in pass 2: ReAct trajectories (arXiv 2210.03629), Toolformer API selection (arXiv 2302.04761), and function-calling contract practice ([13]). The connective claim is that contracts define legal moves, utility defines preferred moves, and retry/rollback control defines survivable moves.
