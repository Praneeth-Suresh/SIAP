# Security Policy

## Supported Version

Security fixes are made on the current `main` branch. Please reproduce a report against that branch when practical.

## Reporting a Vulnerability

Do **not** open a public issue for a suspected vulnerability. Open a private [repository security advisory](https://github.com/Praneeth-Suresh/SIAP/security/advisories/new) instead.

Include:

- a concise description of the impact;
- affected paths and the commit or branch tested;
- safe, minimal reproduction steps or a proof of concept;
- any mitigation you have already tried.

Do not include credentials, private data, or a destructive proof of concept. Maintainers will assess the report, coordinate a fix where appropriate, and ask before publicly disclosing the issue.

For ordinary build, documentation, or usage questions, see [SUPPORT.md](SUPPORT.md).
